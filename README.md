### Grading criteria

This assignment will be graded on a pass/fail basis. Passing will be based on the following criteria:

1. **Timely submission.** For each day the homework assignments and the final data science project is turned in late, you will receive 1 penalty point.
2. **The submission of a properly knitted solution.** We will grade your assignment on the basis of the knitted HTML (not PDF!). If you fail to provide the HTML and the Rmd does not compile without modifications, you will receive 2 penalty points.
3. **Effort to work on the problems.** You should clearly indicate what you submit as your solution for every single task. We are not going to penalize you when a solution is not correct. But we want to see that you engaged with the material. If you don't submit a solution at all or the quality is extremely poor, you will receive a penalty point (for each task where an effort is not visible).
4. **The adherence to a clean and efficient coding style.** Write the code with other users/readers in mind. Adhere to the guidelines provided in the tidyverse sessions. That being said, multiple ways lead to the right solution, and you will not be punished for the use of base R or a deviation from the coding style guidelines as long as you consistenly apply a style that serves the purpose of making your code accessible and efficient. If your code is written very sloppily, you get 1 penalty point.
5. **Proper layouting of your output.** Figures need meaningful descriptions. Axes need meaningful labels. The use of colors serves a purpose. Tables need meaningful headers. Round wisely - nobody needs more than 3 decimal points, and often less is sufficient. Every task deserves its own space. Your comments and explanations should be clearly distinguishable from other content of your script. Currently, deviations from this are not penalized, but please make it easy for us to parse your solutions.

If you have received more than 3 penalty points, the assignment is considered "failed". Overall, you should easily be able to pass even if you don't manage to submit correct solutions. What we care about is an honest effort and its proper documentation.
